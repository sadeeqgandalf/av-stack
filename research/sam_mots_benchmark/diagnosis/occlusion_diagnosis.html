Where SAM loses identity under occlusion

SAM 3 and SAM 3.1, zero-shot with the class name as the only prompt, against the benchmark reference TrackR-CNN (Voigtlaender et al., CVPR 2019). Official TrackEval (HOTA, CLEAR, Identity) on KITTI-MOTS val (9 sequences) and MOTS20 train (4 sequences); occlusion events from MOT17's per-frame visibility labels for the same videos (245 events, 204 pedestrians).

SAM 3SAM 3.1 TrackR-CNN (reference)Δ = SAM 3.1 − SAM 3; red where SAM 3.1 is worse ↑ higher is better · ↓ lower is betterscores in %, except counts and ratios

Findings

  1. Identity, not masks. Association accuracy (AssA) is where SAM 3.1 falls furthest behind SAM 3 on every benchmark (Δ -8.7 / -7.7 / -14.7); mask quality is unchanged (LocA Δ within ±0.7).
  2. People are split into several identities. On MOTS20, association recall drops (AssRe Δ -20.3) while association precision does not (AssPr Δ +3.1): SAM 3.1 outputs 1.32 identities per person (SAM 3 1.01).
  3. The loss is caused by occlusion. Without occlusion the ID is kept 98.1% / 94.7% / 88.8% of the time (SAM 3 / SAM 3.1 / TrackR-CNN); through an occlusion 93.6% / 63.3% / 28.3%. The SAM 3.1 − SAM 3 gap grows from -3.4 to -30.3 points (paired McNemar p = 1.6e-15).
  4. Failures are re-identifications. When the ID is not kept, the person is usually found again under a new ID (new ID / lost: SAM 3.1 56 / 10, TrackR-CNN 117 / 12).
  5. Longer occlusions are the open problem. For occlusions of 2 s or more the ID is kept 73.1% / 36.0% / 4.3% of the time; SAM 3 is the strongest tracker but also degrades there.

Notation as computed by TrackEval (Luiten et al., IJCV 2021) and by our occlusion analysis

HOTAα=DetAα⋅AssAα,HOTA=1|A|∑α∈AHOTAα

HOTA. A = {0.05, 0.10, …, 0.95} (|A| = 19). At each localisation threshold α, a predicted mask matches a ground-truth mask if their IoU ≥ α (one-to-one). DetA, AssA, AssRe, AssPr and LocA are averaged over the same 19 thresholds, so the reported HOTA is not √(DetA · AssA) of the averaged values.

DetAα=|TPα||TPα|+|FNα|+|FPα|

DetA. Detection accuracy: matched masks over all ground-truth and predicted masks.

AssAα=1|TPα|∑c∈TPα|TPA(c)||TPA(c)|+|FNA(c)|+|FPA(c)|

AssA. For a match c between ground-truth object g and predicted identity p: TPA(c) = matches with the same pair (g, p); FNA(c) = frames in which g is present but not matched to p; FPA(c) = frames in which p is present but not matched to g.

AssReα=1|TPα|∑c∈TPα|TPA(c)||TPA(c)|+|FNA(c)|

AssRe. Association recall. Low AssRe: one object is split over several identities.

AssPrα=1|TPα|∑c∈TPα|TPA(c)||TPA(c)|+|FPA(c)|

AssPr. Association precision. Low AssPr: one identity covers several objects (a merge).

LocAα=1|TPα|∑c∈TPαIoU(c)

LocA. Mean mask IoU of matched pairs: segmentation quality.

R=NkeptNkept+Nswitched+Nlost,Δ=xSAM 3.1−xSAM 3

R and Δ. R: identity recovery over occlusion events the tracker was following just before (matched within 1 s before; mask IoU ≥ 0.5). Kept: same ID at the first match within 2 s after; switched: a different ID; lost: no match within 2 s. Δ: difference of any metric x.

Method and limits

  • Models run as in Meta's official notebooks (text prompt on frame 0, then propagation); SAM 3.1 with max_num_objects=128, its model default. GPU-memory offloads were verified to give byte-identical outputs. TrackR-CNN: the official outputs shipped with TrackEval, which reproduce its published sMOTSA.
  • Occlusion event: MOT17 visibility < 0.25 on consecutive frames, with the person visible (≥ 0.25) just before and after; duration = frames / fps. Thresholds were fixed before results; TrackR-CNN was added afterwards with the same definitions.
  • Pedestrians only for B–D (KITTI has no visibility labels). 24 of 228 people could not be linked to a MOT17 track and are excluded; events a tracker was not following beforehand are excluded from its R (Table C). The ≥ 2 s bin is small (n ≈ 25), hence wide intervals.
  • Open question for the solutions phase: SAM 3.1's multiplexed memory under crowding (its log reports bucket subscription of 1350% on MOTS20-02).
